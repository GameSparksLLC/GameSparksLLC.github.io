# Asset sources

- `images/gamesparks-logo.webp`: legacy web version of the GameSparks owner’s supplied desktop logo, no longer used by the site.
- `images/gs-icon.webp`: WebP version of the GameSparks owner’s `GSSite Assets/GSIcon.png`, used in the site footer.
- `images/nyan-portrait.webp`: lossless web version of the Horde Survivor Arena 3D authored character selection art at `Assets/_Game/Visuals/2D/Main Menu/Equipment/gear_character_select_nyan.png`. The source PNG is not shipped with the site.
- `images/gs-nav-icon.webp`: lossless, downsampled web version of the GameSparks owner’s `GSSite Assets/GSNavIcon.png`, used in the navigation bar.
- `images/gs-favicon.png`: optimized 96 × 96 website icon derived from the GameSparks owner’s `GSSite Assets/GSFavIcon.png`.
- `images/topographic-tiling.webp`: lossless WebP contour mask derived from the GameSparks owner’s `GSSite Assets/Topographic_Tiling.png`. Its line opacity masks the darker yellow hero tint.
- `images/studio-art.webp`: WebP version of the GameSparks owner’s `GSSite Assets/Studio_Art.png`, used in the Studio section.
- `images/banner-back.webp`: WebP version of the GameSparks owner’s `GSSite Assets/Banner_Back.png`, used as the clipped game-card art background.
- `images/banner-front.webp`: transparent WebP version of the GameSparks owner’s `GSSite Assets/Banner_Front.png`, used for the two-character game-card artwork.
- `images/crown.webp`: transparent WebP version of the GameSparks owner’s `GSSite Assets/Crown.png`, used as the game-card accent.
- `hero/luna/luna-showcase.glb.gz`: compressed website-only export of Luna, retaining her skinned mesh, the idle body motion, and only the smile and blink blendshapes used by the showcase. The arm pose is fixed in the export; unused clips and face shapes are omitted.
- `fonts/Fredoka.ttf`: Fredoka variable font from the Google Fonts repository, licensed under the SIL Open Font License 1.1. The full notice is `fonts/OFL.txt`.
